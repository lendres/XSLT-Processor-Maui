# XSLT-Processor-Maui
An XSLT processor.

## Requirements

Version 0.4.0 and later require .NET 10 for Windows, DigitalProduction.CommandLine 0.7.0, and DigitalProduction.Maui.AppToolKit 0.14.0. Build with the .NET 10 SDK, its default C# 14 language version, and MAUI Windows workload.

Version 0.3.0 is the final .NET 9 release and is no longer maintained.
